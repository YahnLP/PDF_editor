# Polices incluses (identification et ajout de texte)

Polices libres sous licence **SIL Open Font License 1.1**, sous-ensemble latin (français inclus), extraites des paquets npm `@fontsource/*` :
Barlow, Barlow Condensed, Barlow Semi Condensed, Inter, Roboto, Open Sans, Lato, Montserrat, Poppins, Source Sans 3, Oswald, Nunito, Merriweather, Lora, Playfair Display, Roboto Mono.

Elles servent à reconnaître la police d'un texte dessiné (image, scan, PDF OCR) en comparant la forme des lettres, puis à réécrire le texte à l'identique.
La licence OFL autorise l'usage, l'intégration dans un document et la redistribution avec le logiciel ; chaque famille reste sous la licence et le copyright de ses auteurs (voir les paquets `@fontsource/<famille>`).
